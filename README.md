# 🚀 DevLens AI

> **An AI Developer Assistant that helps developers review, explain, debug, optimize, and improve code from one intelligent workspace.**

DevLens AI is a full-stack AI-powered developer platform built using the MERN stack and Groq's Llama models. It combines multiple developer tools into a single workspace, allowing users to analyze code, generate fixes, optimize performance, export reports, and manage review history.

---
## ✨ Features

- 🤖 AI-powered Code Review
- 💡 Explain Complex Code
- 🐞 Bug Detection
- ⚡ Performance Optimization
- 🔧 AI Code Fixes
- 💻 Monaco Code Editor
- 📄 Export Reviews as PDF
- 📋 Copy Improved Code
- 📚 Persistent Review History
- 🔍 Search & Filter Reviews
- 🔒 JWT Authentication
- 🛡️ Rate Limiting & Secure APIs

---

## 🎯 Problem Statement

Developers often rely on multiple tools for code reviews, debugging, optimization, documentation, and report generation. Switching between these tools interrupts workflow, reduces productivity, and makes code analysis less efficient.

---

## 💡 Solution

DevLens AI brings these capabilities together into a single AI-powered workspace. Developers can review, explain, debug, optimize, and improve code while maintaining a searchable history of their analyses and exporting professional reports—all from one application.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/ishwari03/devlens-ai.git
cd devlens-ai
```

### Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```env
PORT=3000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GROQ_API_KEY=your_groq_api_key
```

Run the backend:

```bash
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
